# C盘突然被占用几十上百G？揭秘 AMD 显卡 PPC 文件夹爆满 Bug 与彻底解决指南

最近不少使用 AMD 显卡（A卡）或 AMD 处理器的主机用户遇到了一件怪事：**明明没下载什么大软件，C盘空间却突然迅速爆满、一路狂飙红线！** 经过排查，罪魁祸首往往是位于 `C:\ProgramData\AMD\PPC` 路径下的一个隐藏文件夹。

今天我们就从技术原理、应急清理到源头拦截，帮大家彻底根治这个 AMD 驱动的“吸血”Bug。

## 🔍 问题分析：为什么 C:\ProgramData\AMD\PPC 会狂写入？

`C:\ProgramData\AMD\PPC` 目录下存放的文件，本质上属于 **AMD 用户体验计划（AMD User Experience Program / Telemetry）** 的遥测数据与系统日志。

按照正常设计，驱动程序只会定期向这个文件夹写入少量的性能日志（CSV 文件、temp 临时文件及 compress 压缩包）。然而在某些驱动版本或系统环境下，**AMD 的遥测服务会出现“日志轮转写死循环”的已知 Bug**——导致后台进程以极其恐怖的速度无限追加写入日志，瞬间吃掉数十甚至上百 GB 的 C 盘空间！

**安心结论：** 该文件夹内的所有 `.csv`、`.temp` 以及 `compress/upload` 目录下的文件**均非系统或显卡驱动运行的必需文件**，删掉不仅不会影响显卡性能，反而能瞬间拯救你的 C 盘！

---

## 🛠️ 三步彻底根治 AMD PPC 爆满 Bug

### 第一步：清理积压文件

1. 打开文件资源管理器，在地址栏输入并回车：
   `C:\ProgramData\AMD\PPC`
2. **全选（Ctrl+A）并彻底删除** 该文件夹内的所有文件及子文件夹（包括 `compress`、`temp`、`upload` 和 `.csv`）。

---

### 第二步：关闭 AMD 遥测（源头停止写入）

光清理文件还不够，必须关闭遥测服务，否则后台还会继续写入：

#### 方法 A：通过 AMD 驱动控制面板关闭（推荐）
1. 打开 **AMD Software (Adrenalin Edition)** 显卡控制面板。
2. 点击右上角的 **设置（齿轮图标） ➔ 首选项（或常规）**。
3. 找到 **AMD 用户体验程序** 选项，将其切换为 **取消参与 / 离开（Leave Program）**。
![](/blogs/amd-ppc-c-drive-fix/7bc711988ea42b74.png)
---

### 第三步：防御性设置（防止未来更新驱动后重蹈覆辙）

为了防止后续更新显卡驱动时该服务被强制重新拉起，我们可以给 PPC 文件夹加一道“只读锁”：

1. 确保 `C:\ProgramData\AMD\PPC` 文件夹内部已被完全清空。
2. 返回上一级目录（`C:\ProgramData\AMD`），右键点击 **PPC** 文件夹 ➔ 选择 **属性**。
3. 切换到 **安全** 选项卡 ➔ 点击 **编辑**。
4. 依次选择当前用户以及 `SYSTEM` / `Administrators` 组，在下方的权限列表中勾选 **拒绝 - 写入**。
5. 点击确定应用。这样一来，即便是驱动后台再次误触发写日志指令，也会因没有权限而无法再向该文件夹产生任何大文件。
